// SYSTEM ARCHITECTURE 02

WHAT CAN WE BUILD WITH AI?

The Complexity Escalation Ladder: Pick the Right Level for Your 48h Goal

Level 1: Zero-Backend Single File (HTML + SVG + Canvas)

Use Case: Visual simulations, interactive educational tools, orbital mechanics visualizers, satellite dashboards.

⚡ Vibe Code Ready: 1 prompt (5-10 mins) | Deploy: GitHub Pages in 10s

Level 2: Data Science / Scripting (Python + Streamlit / FastAPI)

Use Case: Processing NASA NetCDF, GeoTIFF, planetary CSVs, satellite computer vision.

⚡ Build Time: 1-2 hours | Deploy: Hugging Face Spaces / Streamlit Cloud

Level 3: Modern Webapp (Next.js / Node.js / Laravel / Tailwind)

Use Case: Multi-page platforms, user dashboards, interactive 3D globes (CesiumJS, Three.js) with API routes.

⚠️ Build Time: 4-8 hours | Best with: Bolt.new, v0, Cursor

Level 4: Full Containerized Stack (Docker, Postgres, Microservices)

Use Case: Complex spatial databases (PostGIS), custom AI fine-tuned inference pipelines.

⚠️ Hackathon Hazard: Risk of getting bogged down in infra bugs.

// METHODOLOGY 03

THE "VIBE CODING" PLAYBOOK

How to Steer LLMs Without Losing Control of Your Codebase

1. What CAN You Vibe Code?

  • Interactive SVG infographics & animated science models
  • Tailwind/CSS cyber-HUD dashboards & slick landing pages
  • Data parsing scripts (converting NASA JSON/CSV into charts)
  • Game loops & Canvas 2D orbital gravity simulations

2. What Needs Strict Guardrails?

  • Authentication & secrets management (.env leaks)
  • Complex state management across 10+ nested components
  • Astrodynamics math (always feed known Kepler equations to prompt!)
  • Third-party NASA API rate limits & token limits

3. The 3 Golden Rules

  • Single Responsibility: Ask for 1 component or 1 feature per prompt
  • Inspect the Diff: Don't blindly accept full file rewrites
  • Always Provide Context: Feed the schema or exact NASA sample payload first

The Hackathon Secret Formula: "Prompt for the layout first, then prompt for the math/physics engine, then prompt for interactive sliders and sound/visual polish."

Tech Stack Tier Pros (Hackathon Advantage) Cons & Gotchas Vibe Coding Speed Deploy Reliability
Single-File HTML / SVG / JS Zero dependencies, opens offline, instant preview, 0 deploy friction Hard to scale beyond 800 lines of code; limited to client-side data 🚀 5 - 15 mins 100% (Never breaks)

// MISSION SUCCESS 08

DEPLOYMENT & SUBMISSION SURVIVAL GUIDE

The Final 10% That Wins NASA Space Apps Challenges

Instant Deployment

  • GitHub Pages: Push single HTML to repo -> Settings -> Pages (instant free SSL)
  • Vercel / Netlify: Drag-and-drop folder or git push for Next.js / HTML
  • Hugging Face Spaces: 1-click Python Streamlit host

Top 3 AI Pitfalls

  • Context Rot: Asking for too many edits in one chat turns code into spaghetti. Start fresh chats!
  • Hallucinated Datasets: Always feed real NASA API JSON schemas to the prompt.
  • Docker Trap: Don't spend 12 hours debugging Docker configs.

Winning Submission Formula

  • Live URL that works: Judges test it on mobile & desktop
  • 30-second screen recording: In case the live site is slow
  • Clear scientific impact: Which NASA dataset was utilized?
